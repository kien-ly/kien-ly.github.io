# Story Bank Template

Prepare **8–10 stories** that together cover every competency. Most questions can be answered by adapting one of them.

## Coverage matrix

| Story (short name) | Ownership | Dive deep | Conflict | Leadership | Failure | Ambiguity | Impact |
|---|---|---|---|---|---|---|---|
| e.g. Lakehouse governance layers | ✅ | | | ✅ | | ✅ | ✅ |
| e.g. Streaming lag incident | ✅ | ✅ | | | ✅ | | |
| e.g. LLM SQL migration | | ✅ | ✅ | | | ✅ | ✅ |
| … | | | | | | | |

## Template (copy per story)

```markdown
### Story: <short name>

**One-line summary:** <what you did and the result in one sentence>

**Situation** (20 s): company/team, scale, why it mattered to the business.
**Task** (10 s): your specific responsibility / the goal.
**Action** (60–90 s): 3–4 concrete actions YOU took, decisions and trade-offs, obstacles.
**Result** (20 s): numbers (latency, cost, incidents, users, hours saved) + business outcome.
**Learning**: what you'd do differently.

**Likely follow-ups:**
- Why that approach over <alternative>?
- What was the hardest part?
- What did others contribute?
- How did you measure the result?
```

## Quality checklist

- [ ] Every story has at least one number
- [ ] "I" for your actions, "we" only for team context
- [ ] Each story fits in 2–3 minutes spoken
- [ ] You can go 3 levels deep on the technical details
- [ ] At least one genuine failure story
- [ ] At least one conflict story where you didn't "win"
